## 📌 Loyiha haqida
Ushbu dastur oilaviy qandolat fabrikasining kundalik ishlab chiqarish va savdo jarayonlarini to'liq raqamlashtirish uchun maxsus ishlab chiqilgan. Tizim internet bor joyda bulut (Supabase) bilan doimiy sinxronlashadi, internet bo'lmaganda esa 100% oflayn rejimda (PWA) uzluksiz ishlayveradi.

---

## ✨ Asosiy Imkoniyatlar

1. **📦 Xomashyo Ombori (Warehouse):**
   - Asosiy masalliqlar (un, shakar, sariyog', tuxum, kakao, quyiltirilgan sut va h.k.) qoldig'ini avtomatlashtirilgan nazorati.
   - Ishlab chiqarishga qarab masalliqlarni real vaqtda sarflash.

2. **🧾 Kassa va Termal Cheklar (Thermal Receipts):**
   - Har bir savdo uchun professional supermarket cheki ko'rinishidagi yuk xatlari (nakladnaya).
   - Kunlik yakuniy kassa hisoboti va **Cheklar Tarixi** arxivi (qog'oz chek dizaynida).
   - Cheklarni 1 tugma bilan chop etish (Print) yoki do'kon egalariga Telegram orqali yuborish.

3. **📍 Do'konlar va GPS Logistika (Stores & Navigation):**
   - Mijoz do'konlar ro'yxati, ularning qarzdorligi va sotuv hajmlari.
   - Do'konning aniq GPS koordinatasini saqlash va Google Maps orqali 1 bosishda to'g'ridan-to'g'ri navigatorni ishga tushirish.

4. **⚡ Offline PWA (Progressive Web App):**
   - Mobil telefonga ilova (APK) kabi o'rnatiladi.
   - Internet uzilib qolsa ham to'liq ishlaydi (`Service Worker v9`).

5. **🎨 Premium UI / UX:**
   - **Glassmorphism & Berry Dark** mavzusi.
   - Emojilarsiz, faqat professional FontAwesome vektor piktogrammalari bilan ishlangan chiroyli interfeys.

---

## 🛠 Texnologiyalar
- **Frontend:** HTML5, Modern Vanilla JavaScript (ES6+), Tailwind CSS
- **Offline / PWA:** Service Worker Cache API, Web App Manifest
- **Bulutli Baza (Backend):** Supabase (PostgreSQL BaaS)
- **Deployment:** Netlify Edge CDN (avtomatlashtirilgan deploy)
- **Logistika:** W3C Geolocation API & Google Maps Platform
